# LogSift

LogSift is a Node.js + Express-based log analysis tool that processes server log files and generates insights such as:

- Top requested IPs
- Most hit endpoints
- Slowest requests
- Error-prone endpoints

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/LogSift.git
cd LogSift

Install dependencies:
npm install

Run the Application
npm run dev
